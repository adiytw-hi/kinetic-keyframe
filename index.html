The horizontal Bézier coordinate represents normalized time; vertical coordinate controls interpolated progress. Values outside 0–1 can deliberately move beyond a keyframe. Select Cubic Bézier interpolation to apply this curve to the animation.

05 / Creative challenges

Guided animation tasks

0/3 complete

1. Anticipation — move back before moving forward

Add an early keyframe in the cube's track (before 40% of its duration), and move its X position at least 0.25 scene units behind the first keyframe while the endpoint remains ahead.

2. Timing — make the motion snappier

Set the overall duration to 3 seconds or less and select Cubic Bézier interpolation. Inspect the timing curve and how the position graph changes.

3. Spacing — show the ease-in/ease-out pattern

Select Smoothstep; enable onion skin and comparison. Check how equal-time ghost frames cluster near a segment's endpoints.
